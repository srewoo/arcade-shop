# Lantern Bridge UI/UX fixes (2026-11-12)

Result: all 7 audit issues addressed (6 Fixed, 1 Fixed in a different way: #6 was never blocked). Tests 82 passed, build OK, no console errors, no h-scroll.

## Audit issues
1. High, Cross cut off on phone/landscape: FIXED. HUD is now a 3-row grid in landscape (info scrolls; Cross+Undo+Hint dock and Restart/Levels row pinned). Portrait keeps the sticky dock, which now holds Cross, Undo and Hint together. Measured Cross fully visible with no scroll at 400x860 (levels 1 and 21) and 860x400 (before: bottom 401 of 400 at landscape; now 328). Result dialog also fits 860x400 (2-column buttons).
2. Medium, empty "Rules" heading: FIXED. Summary is now informative ("Rules: 2 at a time, slowest sets the pace" / raft equivalent), open by default on roomy screens, rules merged into the info card.
3. Medium, empty flat scene: FIXED. Figures about 30% larger (--actor-w up to 9rem), textured banks, original SVG foreground (grass, rocks, reeds, glowing lamp posts), moon is now a CSS crescent placed inside the sky so it is never clipped, stars restricted to the sky band. Desktop scene already fills the viewport.
4. Medium, hint-capped stars contradict copy: FIXED. Pure `winCopy` (src/puzzle/resultCopy.ts): par+hint says "You found the best route, but a hint was used, so the stars stop at 2." and shows the third star as a dashed-outline "withheld" star; "Perfect" only without hints. "Best possible" reworded to "Best route". Star rule stated up front: HUD line "3 stars: best route, no hints", onboarding line, Hint button tooltip, help text.
5. Medium, onboarding box and minutes unit: FIXED. Banner shortened (3 lines to 2 on desktop, 2 on phone; hidden in short landscape to save space). Badges read "1 min".
6. Low, no skip for 1.5s crossing: FIXED/not needed. Code never locks Cross during the 380ms FLIP animation, so it can be pressed immediately; the audit delay was test waiting. No change.
7. Low, title scene better than play scene: FIXED via #3 (play scene now has the same style of characters plus decor).

## Collection-wide items
- Scene fills desktop viewport: already true in play; title art enlarged (46dvh, up to 34rem).

- Win payoff before card: lamp flare, travellers hop, confetti and win sound play first; the card opens after 1500ms (450ms with Reduce motion). Earned stars pop in gold (motion on only).
