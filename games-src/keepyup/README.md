# Keepy Up

Tap the ball to keep it up; where you strike it sets the bounce angle and spin. Modes: Classic, Two Balls (unlocks at 25 in Classic), Windy. Keyboard: arrows aim a reticle, Space kicks, X snaps the reticle under the lowest ball. Original game, code-drawn art, synthesised audio. Tuning: `src/config.ts`. Debug hooks: `?debug=1` exposes `window.__keepyup`.
